# adapter 0.3.2 装配说明（0.3.1 基底 + 现役增量）

> 公开仓不复制第二套整树：`deploy/adapter/` 是 **0.3.1 整面快照**（83 个运行时件），
> 0.3.2 终态以 **基底 + `deploy/reconstruct/0.3.2/adapter/files/` 覆盖** 得到。
> 装配后=生产活件树 87 个运行时件（生产记录另有 2 个宿主 `.bak`，不分发）。
> 逐件验收账=[`0.3.2-MANIFEST.md5`](0.3.2-MANIFEST.md5)。

## 1. 装配

```bash
# <repo>=公开仓根；<home>=部署用户家目录
rm -rf /tmp/adapter-032
cp -a <repo>/deploy/adapter /tmp/adapter-032
cp -a <repo>/deploy/reconstruct/0.3.2/adapter/files/. /tmp/adapter-032/
cd /tmp/adapter-032
md5sum -c <repo>/deploy/adapter/0.3.2-MANIFEST.md5
# 87/87 OK；build_repack_cuda.sh 的行 md5=e1aea6d1（公开脱敏形），
# 生产同名件=cd6c7707（仅注释中的家目录不同），其余 86 件与生产逐字节相同。
```

## 2. 落位与备份

```bash
# 先备份现役 adapter（回退用；保留最近两份）
cp -a <home>/migrate-assets/dsv41/adapter \
     <home>/migrate-assets/dsv41/adapter-bak-pre-032-$(date +%Y%m%d-%H%M%S)
# 整树替换（adapter 是 bind mount 供给面；四机必须同批同内容）
# 用 -a 不用 --delete：保留宿主侧 .bak/现场文件；本版没有“被移除”的运行时件
rsync -a /tmp/adapter-032/ <home>/migrate-assets/dsv41/adapter/
```

> 四机全等律：adapter 由宿主 bind mount 进容器，四机必须同批落同一棵树；
> 只换 head 会得到混形栈。落位后 `md5sum -c` 再跑一次。

## 4. 绑定律（最高危）

`seam_mount.py`、`sparse_wire.py` 等 adapter 件与 r032c 引擎件是**同一批**：
新镜像 + 旧 adapter 会把上游修复静默回退（`publish_decode` 重绑/`from_metadata`
路由丢失），表现为可跑但长稳/位等异常。升级时 **镜像层与 adapter 层必须同窗切换**；
不要只升其中一面后开判读窗。

## 5. 回退

```bash
rsync -a --delete <home>/migrate-assets/dsv41/adapter-bak-pre-032-<ts>/ \
      <home>/migrate-assets/dsv41/adapter/
```

回退后必须复靴；旧 adapter 配 r032c 属混形，禁止在回退未完成时开流量。
