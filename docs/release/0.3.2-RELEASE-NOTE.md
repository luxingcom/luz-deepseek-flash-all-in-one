## 〇、版本叙事

1. **净线重建**（网络链路重整：管理段重编址、NCCL 网面修复、环网补丁链退役、

## 七、系列衔接与升级路径（0.3.1 → 0.3.2）

**形变化（升级时逐项对表）**：

| 面 | 0.3.1 定版 | 0.3.2 定版 |
|---|---|---|

**兼容性**：HTTP API 无破坏性变更；新增能力=`tool_calls` 结构化成型（issue #1）、
`usage.prompt_tokens_details.cached_tokens` 上报（issue #2）、`/v1/models` 容量
四键（issue #3，缺省关、零行为差）。旧客户端无需改动。

**升级步骤（单靴，≈1.5-2h）**：①registry 拉取/加载 `0.3.2-r032c` 并核 digest；
②切换 env 键面到 CBX1A 同形（或按差异表增量补键）；③切换 adapter 面（逐件回拷
链在案）；④boot IMAGE 指针改 r032c，跑 boot 四查+`tools/serve_flags_gate.sh`

**回退路径**：boot IMAGE 单行回指 `0.3.2-r032` 或 `0.3.1-r3`；env 相邻级回指
CBX1A→E16B2→FB54→WG53；adapter 逐件回拷（A6/R1 两条链）。回退后同样跑 boot
四查+起栈接线闸门（旧形 A8/A9 未接线时闸门应红——这是预期判别，不是回归）。
