### 2.3 结论与缺证

## 三、DSV41_SPARK_PREFILL_TP_SPLIT 作用点与独立性（任务2）

### 3.1 作用点（在役 `spark_prefill_split.py`，0.3.2=aba8c088 谱系）

- 挂钩：sitecustomize.py:305-312——`sglang.srt.layers.attention.deepseek_v4_backend` 模块 exec 时 `spark_prefill_split.install(module)`；自门 `DSV41_SPARK_PREFILL_TP_SPLIT`（缺省 0）+阈值门（MIN_CONTEXT≥32768/MIN_ROWS≥1024）+结构性拒绝（非 DenseBlocks 候选/非 SM121/world∉(4,8) 拒启）。
- 补丁：`DeepseekV4AttnBackend.__init__` 包一层（解析 attn-TP 组+结构性核，:357-421）与 `_low_ratio_index_topk` 换 wrapper（:284-306，`dense_with_split`）。运行语义：**prefill dense-indexer 的查询行按 TP rank 切片**（`partition` :98-104），各 rank 只对本 rank 行跑 `flat_index_logits_tiles`+`topk_transform_ragged_v2`（:215-256），int32 topk id+候选块 id `all_gather` 重组（:258），`write_selection`/`_publish_candidate_metadata(BlockIds…)` 走基面自产出口（:263-271）。无浮点集合通信；init 零集合通信（W21 b1 注记 :400-408）。
- 数据源：`self.token_to_kv_pool.get_low_ratio_index_k_fp4(layer.layer_id, data.k_slots)`（:187）→ memory_pool :1876-1891 → **indexer 池**（DeepSeekV4IndexerKVPool :520-558）的 `get_index_k_fp4`。indexer 池 fp4 性由 `use_fp4_indexer` 决定（缺省 `get_exec().kernel.enable_deepseek_v4_fp4_indexer`，:547-548；低 ratio 池建池处硬 `use_fp4_indexer=True`，:1556）——**独立旗标，不读 SGLANG_DSV4_KV_LAYOUT**；其 68 B/token 恒入两态同价台账（§1.4 A7）。

### 3.2 独立性判读

1. **补丁目标零共享**：split 只写 `deepseek_v4_backend`（`__init__`/`_low_ratio_index_topk`）；kv_fp4 只写 memory_pool 三函数/configurator 重绑/pool_configurator 台账/flash_mla_sm120 入口。四 seam 模块 ∉ split 触面，反之亦然。
2. **数据面共享仅限只读池访问器**，且访问的是 layout 无关的 indexer fp4 池（§3.1）；两态（v41/fork）下该池形相同。
3. **运行态实证**：快慢全部对照靴 split 横幅 `gate=(unset)`（W-b phase2/phase3、RB033、X6R2、PRF-DISCRIM 四窗 head 日志同形）——tp4 :87 的 split 行**不进容器 env**（RB033 §3.1「独立行不进容器（tp4 :150/:188 注记）」），split 在整个快慢对比集里**运行态未参战**。
